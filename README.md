Actividad 3. Uso de Git y GitHub 
A partir del diagrama de flujo de trabajo de Git, replica la estructura de ramas y la historia de commits de la imagen.
Para realizarlo ten en cuenta las siguientes circunstancias. 
•	Crea un repositorio público en GitHub inicial para clonarlo en tu local. Comparte la dirección del repositorio. 
•	Asegúrate del nombre de la rama principal que dispone el repositorio. 
o	master 
o	main 
•	Crea un fichero index.html que irás modificando con cada uno de los commits que vayas realizando. Solo modificaras este fichero, lo que te permitirá ver como van evolucionando cada una de las ramas. 
•	Cada punto en el diagrama debe ser un commit y por tanto una modificación en index.html. 
•	Tienes adjunto a la tarea el resultado final que deberíamos poder descargarnos del respositorio. 
•	Deberás ir subiendo los cambios a GitHub para sincronizar tu repositorio. No es necesario que lo hagas con cada commit, pero si que lo hagas en momentos especiales. 
o	Creación de rama. 
o	Fusión de varios cambios. 
•	Para fusionar ramas hazlo mediante operaciones merge. 
•	No borres ninguna rama.
